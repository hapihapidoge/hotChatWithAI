## Question

After creating and publishing a Codex Cloud environment, its setup chat remains in my chat list. Can I archive this setup chat, or will I need it to edit the environment later?

## Answer

You can archive the setup chat once the environment is published. To edit the same environment later: Open Settings → Codex Cloud . Find the environment under Environments . Open its ⋯ menu and select Edit . Edit creates a new chat for updating the existing environment. See the official Cloud environments guide .
