## Question

我想让 agent 每天搜集用户向 AI 提出的优质问题和回答，提交到我的 GitHub 上，并且可以在 public network 上查看。这个东西应该怎么设计？

## Answer

最小可行版本可以分成三层：内容入口、审核整理、公开展示。内容入口负责收集候选问答，可以来自手动 JSON、GitHub Issue、表单、浏览器插件或聊天导出，但必须先做授权和匿名化。审核整理层负责给每条问答补标题、摘要、标签、模型、质量理由，并过滤掉隐私、低质量和不可公开内容。公开展示层用 GitHub Pages 发布静态站点，仓库保存原始 curated 数据、每日构建出的 JSON 和 Markdown。每天的自动化任务只做两件事：把新增候选转成规范数据，再重新构建 public 目录并提交。这样它既像知乎一样能浏览和归档，又保留 GitHub 的版本历史和公共可见性。
