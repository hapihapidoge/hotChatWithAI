## Question

The feature is explained below: The user enters a search query: E.g. "moons of Saturn" The search produces web results, that are scrapped to parse webpages, and detect names. A list of names related to the topic are produced, like (for the "Moons of Saturn" query): "Titan", "Dione", "Hyperion", "Janus"... After this list is produced, options are presented to "use" this list for any purpose, like creating folders/virtual desktops using this name etc. Optionally including a feature to set maximum number of names to use. Is this an agentic AI feature, or it's just non-agentic name extraction funcionality? It seems that a such feature would predate the AI bubble era.

## Answer

An AI agent is a system that independently pursues a given goal, makes its own decisions about the steps required to achieve that goal, and can use appropriate tools or functions to do so. An agent is a software system that can perceive information, reason about a task, make decisions, and take actions to achieve a goal. AI agents may operate autonomously or semi-autonomously and can use tools, APIs, databases, or external services as part of their work. Agent Tag Wiki Using tools does not automatically make a system an AI agent. An AI agent is not simply any system that uses multiple functions or tools. What matters is autonomy and decision-making capability. For the feature described, it would initially be more accurate to refer to it as an AI-assisted function or automation: Search Extract data from websites Identify relevant names Create a list Use those names for further actions Even if an LLM is used, that does not automatically make the function agentic. It would become agentic when the system is given a goal and independently decides which steps, tools, and actions are necessary, dynamically adapts the process, and makes further decisions based on the results. So, your assumption is correct, that the basic functionality already existed before today AI/agent boom.
