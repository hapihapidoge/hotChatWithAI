## Question

How to prompt image generators to produce text with typography resembling real typefaces? Like Trajan-style typefaces (very often used in movie posters and such). And what model is better for this (GPT-Image/Nano Banana/Flux/Stable Diffusion/etc.)?

## Answer

Yes. When specified in the prompt (like "lettering in style of the Trajan typeface" or "ancient Roman lettering"), modern image generation engines can reliably reproduce the typeface style, albeit not exactly like the real Trajan typeface or resembling it. For better results is it recommended to use the generator to generate images and then use image editors like Photoshop to add text using the actual typeface, optionally with effects like bevel & emboss and textures to resemble golden/silver/etc. text.
