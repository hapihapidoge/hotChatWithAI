## Question

Which GenAI tools are suitable for creating Epic: The Musical -style musical compositions with original lyrics, and how should I prompt them? The musical itself is an adaptation of Homer's Odyssey.

## Answer

If the goal is to create a truly original musical, I would not try to simply have an LLM write or copy a song like EPIC The Musical. It works better to describe the characteristics you want and then develop your own work, step by step from that. I would distinguish between two tasks: 1. LLM creates: Story, characters, dramaturgy, lyrics and song structure Here you can use the well-known online ChatGPT, Claude, Gemini, etc. or local AIs. You could also divide each task into smaller subtasks and have each of them processed by different LLMs. If you want to use this repeatedly and professionally, you could also build agents with a main conductor that controls and approves everything, but I don't know if it is worth the effort and whether the know-how is available. 2. Music AI creates: Melody, instrumentation, vocals and production, for example, Suno or Udio are suitable here. Don't copy the artist or the musical, but describe the characteristics Write an epic musical song with a mythological atmosphere, orchestral accompaniment, dramatic character development, strong contrasts between quiet and intense passages, and a big emotional finale. Use the following characteristics: Genre: Musical, Cinematic, Mythological Mood: dramatic, melancholic, heroic Instruments: strings, brass, deep percussion, choir Vocals: Solo, Duet, alternating vocals Dramaturgy: start quietly, build tension,...
