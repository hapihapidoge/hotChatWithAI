## Question

I’m using Codex on macOS and have granted the required system permissions for Computer Use, but I’m still having trouble getting it to work. Is there a separate setting in Codex that also needs to be enabled?

## Answer

Go to Settings → Plugins → MCPs → Servers and enable the computer-use toggle. This toggle is separate from the macOS permissions. In my case, it was disabled. See the official Computer Use setup guide for the other setup requirements.
