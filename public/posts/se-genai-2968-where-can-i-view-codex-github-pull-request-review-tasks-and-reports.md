## Question

I used to view Codex GitHub review tasks in what is now called Codex Cloud (Legacy). I've checked Codex Cloud, Codex Cloud (Legacy), and Code Review, but can't find the tasks in the current interface. A completed Security review also provides a Security Report link in the format https://chatgpt.com/codex/cloud/tasks/[task-id] . When I open it while signed in, it redirects me to chatgpt.com instead of opening the report. How can I open the underlying review tasks to inspect their progress, results, or errors?

## Answer

OpenAI’s AI-assisted support confirmed there’s no equivalent path for browsing past legacy GitHub review tasks in the new Codex Cloud interface. The documentation also notes that existing cloud code review wasn’t migrated to the new cloud environments.
